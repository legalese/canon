This row read that file byte for byte (sha256 `066301837e6413cf635bf0dc21a44186705b9d892b04a2cdd1036afbd9e269f2`).

**It reproduces far more of the text than the `legalese` row.**
The modules quote the Code's sections in comments beside the rules, and the inert style carries statutory words inline as string literals; several generators copy each section's text out of the source file mechanically.
How much of the Code appears verbatim across the 27 encoding modules has not been measured; for the encoded sections, expect most of it.
