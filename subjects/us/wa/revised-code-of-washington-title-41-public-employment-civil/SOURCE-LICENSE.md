# Source license

The text of **Revised Code of Washington, Title 41 (Public Employment, Civil Service, and Pensions), Chapter 41.40 - Washington Public Employees' Retirement System** is published on the [Revised Code of Washington (RCW) - Washington State Legislature / Office of the Code Reviser](https://app.leg.wa.gov/RCW/).

- **Terms**: CAUTION - Washington is the one jurisdiction in this group whose register affirmatively asserts copyright in the code itself. The Legislature's disclaimer page states that a user intending to obtain the RCW or the WAC 'for the purpose of selling the same is advised to contact the Washington State Statute Law Committee, which claims copyright for both codes', and the footer adds '(c) Copyright 2026. All Rights Reserved.' There is no licence, no open-data grant and no permission mechanism published on the site, and the RCW index notes that only the certified PDFs in the Code Reviser's RCW Archive are the official publication. What the government edicts doctrine means for the text itself: under Georgia v. Public.Resource.Org, 590 U.S. 255 (2020) (and Banks v. Manchester, 128 U.S. 244 (1888)) the enacted text of Washington's statutes is not copyrightable at all, because it is the work of the legislature acting as lawmaker, and a state's assertion cannot create a copyright the doctrine denies. The Statute Law Committee's claim can therefore only bite, if at all, on the Code Reviser's editorial layer - the compilation and arrangement, section captions, reviser's notes, cross-reference notes, digests and dispositions tables - and not on the statutory text. Reuse and adaptation of the enacted text are accordingly lawful, which is why open_licence is recorded as true; but A HUMAN SHOULD MAKE THE FINAL CALL before any commercial redistribution, because the register's own words point the other way and it is the doctrine, not the register, doing the work here. The code is compiled by a public office (the Office of the Code Reviser), not by LexisNexis or Thomson Reuters under contract.

In the United States the text of a statute is not copyrightable: it is an edict of government (*Georgia v. Public.Resource.Org*, 590 U.S. 255 (2020)). A register's copyright notice can still cover a publisher's annotations, headnotes and numbering, which this corpus does not reproduce.
