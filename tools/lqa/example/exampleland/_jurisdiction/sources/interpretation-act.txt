FICTIONAL. Written for the LQA checker's worked example. Exampleland does not exist.

12. Age
A reference in a written law to an age in months is a reference to complete calendar months,
counted from the day of birth.

20. Time for doing things
Where a written law requires or permits a thing to be done and no time is fixed for doing it,
the thing is to be done with all convenient speed.
