# Source license

The text of **Iowa Code Chapter 476 (Public Utility Regulation)** is published on the [Iowa Legislature - Iowa Code (Legislative Services Agency)](https://www.legis.iowa.gov/law/iowaCode).

- **Terms**: The register asserts no copyright over the Iowa Code and publishes no licence: the only statement is a disclaimer about accuracy plus a pointer to the official edition, and the separate 'Official and Unofficial Editions' page explains the UELMA designation scheme under Iowa Code ch. 2B rather than restricting reuse. Under the government edicts doctrine (Georgia v. Public.Resource.Org, 590 U.S. 255 (2020)) the statute text is not copyrightable, so reuse and adaptation are both permissible. Two narrower points from the same disclaimer page: session photographs on the site are owned by the Associated Press and are expressly not reusable (irrelevant to statute text, but do not scrape images), and only an edition designated official by the Legislative Services Agency is authoritative, so an adaptation should cite the edition it was built from. The Code is compiled in-house by the Legislative Services Agency, not by a commercial publisher.

In the United States the text of a statute is not copyrightable: it is an edict of government (*Georgia v. Public.Resource.Org*, 590 U.S. 255 (2020)). A register's copyright notice can still cover a publisher's annotations, headnotes and numbering, which this corpus does not reproduce.
